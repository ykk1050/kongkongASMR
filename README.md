# 소리 콩콩 학습 산책

떨어져 있는 타일 사이를 콩콩 뛰어다니며, 사회·수학 문제의 답을 **한 글자씩 순서대로** 밟는
2D 아이소메트릭 ASMR 학습 게임.

빌드 도구·의존성 없음. 브라우저만 있으면 됩니다.

---

## 실행

```bash
python -m http.server 5178
```

→ http://localhost:5178 접속 후 **"산책 시작하기"** 클릭
(브라우저 자동재생 정책 때문에 클릭 한 번이 반드시 필요합니다.)

`index.html`을 더블클릭해 `file://`로 열어도 동작합니다 — 이때는 내장 폴백 문제 데이터를 씁니다.

**이어폰 착용을 권장합니다.** 캐릭터의 화면 좌우 위치에 따라 HRTF 바이노럴로 정위됩니다.

웹 배포는 [`docs/DEPLOY.md`](docs/DEPLOY.md) 참고 (GitHub Pages 워크플로 포함).

### 조작

**방향만으로는 움직이지 않습니다.** 방향으로 조준한 뒤 점프 버튼을 눌러야 이동합니다.

| 입력 | 동작 |
|---|---|
| 가상 조이스틱 (좌하단) / `W A S D` · 방향키 | 8방향 **조준만** — 갈 곳이 청록 점선으로 깜빡입니다 |
| `Q` `E` `Z` `C` · 넘패드 `7` `9` `1` `3` | **대각선을 키 하나로** 조준 (↖ ↗ ↙ ↘) |
| `쿵` 버튼 (우하단) / `Space` · `Enter` · `J` `K` `F` · 넘패드 `0` `5` `Enter` `+` · 오른쪽 `Shift` `Ctrl` `.` `/` | 조준한 칸으로 **점프** |
| ☰ 메뉴 → **입력 진단** | 브라우저에 실제로 도착한 키를 화면에 그대로 보여 준다 |
| 조준 없이 점프 | 제자리에서 **강하게 내려찍기** (파괴력 2배) |
| ☰ 메뉴 (우상단) | 과목 필터 · 다음 문제 · 소리 끄기 · 조이스틱 켜기/끄기 · **소리 도감** |

조이스틱이나 방향키를 잡으면 착지할 타일에 **청록 점선**이 흐르며 깜빡이고,
바깥으로 링이 퍼져 나갑니다. 어디로 뛸지 확인한 뒤 누를 수 있습니다.
눈·모래처럼 윗면이 흰 타일에서도 보이도록 어두운 밑선과 흰 꼭짓점 표식을 함께 깝니다.

조이스틱은 **손가락이 처음 닿은 자리**가 원점입니다(플로팅 스틱). 패드 가장자리를
짚어도 그 방향이 곧바로 입력되지 않고, 손가락이 반경 밖으로 나가면 원점이 따라갑니다.
스틱을 밀면 패드 위에 **어느 칸이 잡혔는지 청록 점**으로 표시됩니다.

방향 판정은 화면상 45°가 아니라 **실제 아이소메트릭 각도**(±26.6°/±90°/0°/180°)로
합니다. 눈에 보이는 타일 쪽으로 밀면 그 타일이 잡힙니다.

키보드 방향 입력은 **가로·세로 축을 따로** 계산합니다. 축마다 "지금 눌려 있는 키"가
우선이고, 눌린 키가 없는 축만 "방금 톡 누른 키 하나"로 채웁니다. 축마다 하나만
기억하므로 `←`와 `→`가 함께 쌓여 서로 상쇄되는 일이 없습니다 — 예전에는 방향키를
마구 누르면 실제로 그렇게 조준이 0에 갇혀 **점선이 사라지고**, 그 상태로 점프하면
제자리 내려찍기가 됐습니다.

**점프 입력은 버려지지 않습니다** — 예전에는 도약 중(0.30초, 큰 점프 0.44초)에 누른
점프가 통째로 사라졌습니다. 연달아 움직이는 동안에는 상당 시간이 '못 뛰는 구간'이라,
플레이어에게는 "가끔 스페이스가 안 먹는다"로 보였습니다. 지금은 뛸 수 있게 되는
순간까지 요청을 들고 있다가 발동합니다.

**세 키를 동시에 누르지 않아도 됩니다** — 대각선 + 점프는 `↑`+`←`+`Space` 로 3키
동시입력입니다. 값싼 멤브레인 키보드는 3키 롤오버를 전부 받지 못하고, 막히는 조합은
키 매트릭스 배선마다 다릅니다(방향키 묶음에서 특히 자주 일어납니다). 그래서
"WASD로는 되는데 방향키로는 왼쪽 위만 안 된다"가 실제로 생깁니다. 대비책이 둘입니다.

1. **톡톡 이어 누르면 대각선 조준이 됩니다.** `↓` 톡 `→` 톡 처럼 이어 누르면
   가로·세로를 각각 기억해 합칩니다. 조준을 잡은 뒤 점프 키를 누르면 되므로
   한 번에 눌리는 키가 둘을 넘지 않습니다.
2. **`Q E Z C`**(넘패드 `7 9 1 3`)는 키 하나가 대각선 하나입니다.
3. **점프 키도 여러 개** 깔려 있습니다 — `Space` `Enter` `J` `K` `F`,
   오른쪽 `Shift` `Ctrl` `.` `/`, 넘패드 `0` `5` `Enter` `+`.

> **방향만으로는 절대 움직이지 않습니다.** 방향은 조준일 뿐이고, 점프 키를 눌러야
> 이동합니다. 이 규칙은 게임의 핵심이라 어떤 대비책도 이걸 깨지 않습니다.

**조준과 점프를 동시에 눌러도 됩니다.** 사람은 두 키를 정확히 같은 순간에 누르지
못해서, 방향이 몇 ms만 늦어도 그 프레임이 '방향 없음'이 되어 제자리 내려찍기로
끝나 버렸습니다. 지금은 **조준이 없을 때만** 점프 판정을 0.13초 미루고 방향을
기다립니다. 조준이 이미 있으면 한 프레임도 기다리지 않으므로 반응은 그대로입니다.

**그래도 안 되면 ☰ 메뉴 → 입력 진단**을 켜 보세요. 브라우저에 **실제로 도착한 키**를
그대로 보여 줍니다. `Space` 를 눌렀는데 목록에 안 뜨면 키보드가 그 키를 삼킨 것이고
(게임이 손쓸 수 없는 영역입니다), 뜨는데도 안 움직이면 게임 쪽 문제입니다.
둘은 화면만 봐서는 구별할 수 없어서 이 패널을 붙였습니다.

제자리 내려찍기와 헷갈릴 일은 없습니다 — **조준 표시가 켜져 있으면 그 칸으로,
꺼져 있으면 내려찍기**입니다. 화면에 보이는 그대로입니다.

## 게임 규칙

타일은 서로 **한 칸씩 떨어져 떠 있고**, 캐릭터는 타일에서 타일로 점프합니다.

**보드에는 빈 칸(구멍)이 있습니다.** 빈 칸으로 뛰면 떨어져서 **점수 15점을 잃고**
직전 발판으로 돌아옵니다. 그래서 어디로 뛸지가 선택이 됩니다 — 빈 칸을 조준하면
**붉은 점선과 아래 화살표**로 미리 경고합니다.

구멍은 판을 만들 때마다 무작위로 뚫리지만 두 가지를 반드시 지킵니다 —
시작 칸은 절대 구멍이 아니고, 남은 타일은 **전부 하나로 이어져 있습니다**(섬이
생겨 문제 글자를 영영 못 밟는 판이 만들어지지 않도록). 문제 글자도 구멍에는
놓이지 않습니다. 보드 밖으로는 나갈 수 없습니다.

**한 타일에는 한 글자만** 올라갑니다. 답이 `경상북도`라면
`경` → `상` → `북` → `도` 네 타일을 순서대로 밟아야 합니다.

- 한 글자 맞을 때마다: 상승하는 펜타토닉 `톡-톡` + 별빛 + `TOK!` + 초록 파문
- 마지막 글자 완성: `CRACKLE-POP!` `PERFECT!` + 아르페지오 + 팝 14연발
- 순서를 틀리면: 둔탁한 thud, 화면 흔들림, 0.6초 멈칫, **진행 전체 리셋** (−5점)
- 빈 칸에 떨어지면: **−15점**, 0.55초 멈칫, 직전 발판으로 복귀
- 2회 틀리면 힌트와 다음 정답 타일 반짝임이 자동으로 켜집니다
- 이미 밟은 타일을 다시 지나가는 것은 실수로 처리되지 않습니다
- **정답을 밟은 타일은 즉시 복구**됩니다 — 소모성 재질이어도 진행이 막히지 않습니다

### 타일 — 보면 무슨 소리가 날지 안다

재질마다 색·두께·표면 구조가 전부 달라서, 밟기 전에 소리를 예상할 수 있습니다.
메뉴의 **소리 도감**에서 타일 그림과 소리를 나란히 보고 눌러서 미리 들을 수도 있습니다.

| 타일 | 생김새 | 소리 | 밟으면 |
|---|---|---|---|
| 키캡 | 오목한 상판 + 도톰한 테두리 + 스쿱 반사 | **톡** | 눌렸다 스프링 복원 |
| 솜 | 부푼 덩어리 네 개 + 보송한 솜털 | **포옥** | 깊게 눌리고 천천히 복원 |
| 젤리 | 반투명 + 큰 광택 + 안쪽 기포 | **통** | 크게 출렁이며 복원 |
| 나무 | 널판 이음새 + 나뭇결 + 못 자국 | **탁** | 살짝 눌림 |
| 슬라임 | 가장자리에서 흘러내리는 가닥 + 떠오르는 기포 | **찌걱** | 끈적하게 늘어졌다 복원 |
| 유리구슬 | 투명 구슬 + 십자 반사 | **챠랑** | 맑게 오래 울림 |
| 스펀지 | 숭숭 뚫린 구멍 | **뽀드득** | 공기를 머금었다 내뱉음 |
| 낙엽 | 잎맥까지 그린 잎사귀 (밟을수록 줄어듦) | **바스락** | **2번**이면 부서짐 · 2.2초 뒤 복구 · 밟으면 잎이 팔랑이며 날린다 |
| 에어캡 | 볼록한 돔 7개 (터진 자리는 주름) | **뽁** | 밟을 때마다 **알이 2개씩 터진다** · 3번이면 전부 터지고 1.8초 뒤 복구 |
| 구슬볼 | 말랑한 색색 구슬 (밟을수록 사라짐) | **톡톡** | **3번**이면 부서짐 · 1.9초 뒤 복구 |
| 모래 | 끊긴 잔물결 능선 + 세 톤 알갱이 + 눌린 웅덩이 | **사각** | **2번**이면 부서짐 · 2.0초 뒤 복구 · 밟으면 가루가 피어오른다 |
| 눈 | 푸른 그늘의 소복한 둔덕 + 깜빡이는 결정 + 다져진 자국 | **뽀득** | **2번**이면 부서짐 · 2.4초 뒤 복구 |

### 밟았을 때의 시각 효과

소리마다 짝이 되는 연출이 다릅니다. 재질을 보고 소리를 예상하고, 밟으면 그 예상이 눈으로도 확인됩니다.

| 재질 | 임팩트 연출 |
|---|---|
| 키캡 · 나무 | 먼지가 낮게 튀고 표면이 짧게 발광 |
| 솜 · 스펀지 | 부드러운 구름이 부풀어 오름 |
| 젤리 | 잔상 링 세 겹이 연달아 퍼짐 |
| 슬라임 | 실처럼 늘어졌다 끊어지는 가닥 |
| 낙엽 | 각진 파편이 회전하며 튐 |
| 에어캡 | 사방으로 뻗는 섬광선 |
| 구슬볼 | 색색 구슬이 통통 튀며 굴러 나감 |
| 모래 | 아주 작은 알갱이 30여 개가 낮게 흩어짐 |
| 유리구슬 | 십자 섬광 + 반짝이 |
| 눈 | 눈 결정이 흩날림 |

여기에 더해 **모든 타일에 공통으로**:

- 밟은 자리에 **자국**이 남아 서서히 사라집니다 (모래·눈은 발자국, 슬라임·구슬볼은 젖은 얼룩, 나머지는 눌린 그림자)
- 소모성 타일은 단계마다 **균열선이 늘고 살짝 기울어지며**, 표면의 장식이 줄어듭니다
  (잎이 사라지고, 에어캡 알이 터지고, 구슬이 없어짐)
- 완전히 부서지면 윗면이 **네 조각으로 갈라져 날아가고**, 그 자리에 삐죽한 테두리의 **어두운 구멍**이 남습니다
- 파괴·정답 완성 순간에는 **화면 전체가 재질 색으로 번쩍입니다**
- 캐릭터 주변 오라 링은 실제 출력 레벨(RMS)에 맞춰 맥동합니다

남은 횟수는 타일 아래 흰 점으로 표시됩니다.
조준 없이 하는 제자리 내려찍기는 한 번에 **2단계**를 깎습니다.
완전히 부서진 자리는 발판이 사라져 점프해 올라갈 수 없고, 잠시 뒤 되살아납니다.

## 구현된 시스템

**조준 후 점프** — 방향 입력은 8방향으로 양자화되어 착지할 타일을 **표시만** 하고,
점프 입력이 들어와야 포물선 도약이 시작됩니다. 점프 입력은 '눌림 유지' 방식이라
먼저 조준하고 눌러도, 누른 채 조준을 바꿔도 의도대로 뜁니다.
연속으로 뛸수록(체인) 착지 강도가 올라가 소리의 피치와 음량이 커집니다.

**파묻힘 없는 착지** — 캐릭터는 매 프레임 발밑 타일의 **실제 윗면 높이**(`Tiles.surfaceOffset`)를
따라갑니다. 재질마다 두께가 다르고 눌림·파손으로 높이가 변해도 발이 항상 표면에 붙습니다.

**소리 ↔ 시각 결합** — 모든 사운드 호출은 짝이 되는 시각 효과를 함께 냅니다.
재질별 팔레트(`Particles.PALETTE`)가 오디오 재질 키와 1:1로 대응하고,
타일은 소리와 함께 표면이 발광하며, 캐릭터 주변 오라 링은
`AnalyserNode`로 측정한 **실제 출력 레벨**에 맞춰 맥동합니다.

**다단계 파괴** — 소모성 타일은 밟을 때마다 균열이 누적되고 소리가 단계별로 밝아집니다
(`Audio.crack(mat, stage, total)`). 마지막 타격에서만 완전히 부서집니다.

**겹치지 않는 레이아웃** — `safeRect()`가 HUD와 조이스틱의 실제 DOM 위치를 측정해
남는 공간을 계산하고, 보드를 그 안에 맞춰 스케일·중앙 정렬합니다.
세로 여유가 부족한 납작한 태블릿에서는 자동으로 컨트롤 *사이* 공간을 씁니다.
화면 폭에 따라 격자도 4×4 / 5×5 / 6×6 으로 바뀝니다.

**모달 합성 기반 ASMR 오디오** — 두드린 물체는 "감쇠하는 공명 모드의 합"이라는
물리 모형을 그대로 구현했습니다. 재질마다 고유한 비조화 배음비(예: 나무 1 : 2.37 : 5.38 : 9.12)를
가진 3~5개 모드를 쌓고, **트랜지언트 / 바디 / 테일** 3단으로 나눠 합성합니다.
낙엽·모래·눈처럼 공명이 없는 재질은 수십 개의 미세 알갱이를 시간·주파수·좌우로 흩뿌리는
**그래뉼러 텍스처**로 만들고, 눈·스펀지의 '뽀득'은 좁은 대역이 위로 쓸려 올라가는 공명 처프로 만듭니다.
매 타격마다 피치·타이밍·게인이 조금씩 흔들려(휴머나이즈) 기계적 반복이 없고,
잔향은 짧고 어둡게(0.85초) 두어 근접 마이크 감각을 살렸으며, 마스터에 리미터가 걸려 있습니다.
오디오 파일은 여전히 **0개**입니다.

SK.Game.debug.state()          // 페이즈, FSM 상태, 기대 토큰, 타일(재질·균열 포함)
