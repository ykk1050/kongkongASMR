# 타일 표면을 더 진짜처럼 — 직접 그리기 · 저작권 프리 소재 구해 오기

> 구현: `js/tiles.js` 의 `ART` 테이블

---

## 0. 지금 방식과 한계

타일 윗면은 전부 **캔버스 벡터 드로잉**입니다. 이미지 파일이 하나도 없어서
저작권 문제가 없고, 크기를 바꿔도 안 깨지고, 균열·눌림 같은 상태 변화를
그림 안에서 바로 표현할 수 있습니다.

대신 **미세한 질감**에는 약합니다. 모래 알갱이 하나하나, 눈 결정의 서걱거림,
나뭇결의 섬유 같은 것은 원·선 몇백 개로는 흉내만 낼 수 있습니다.
"더 진짜 같게"를 원한다면 아래 세 갈래 중 하나입니다.

| 방법 | 장점 | 비용 |
|---|---|---|
| ① 벡터 드로잉을 더 정교하게 | 파일 0개 유지, 상태 변화 자유 | 코드가 길어진다 |
| ② 절차적 노이즈 텍스처 | 파일 0개 유지, 진짜 질감에 가장 근접 | 캔버스 연산 비용 |
| ③ CC0 텍스처 이미지 | 압도적으로 사실적 | 파일 용량, 라이선스 확인 필요 |

## 1. 무엇이 "재질처럼" 보이게 만드는가

소재를 구해 오기 전에, 지금 그림을 고칠 수 있는 부분부터.
재질감은 **색이 아니라 빛**에서 나옵니다. 모래·눈 타일을 고치면서 실제로 효과가 컸던 순서:

1. **그늘 색을 회색으로 칠하지 않는다.** 눈 그늘은 파랗고(표면하 산란), 모래 그늘은
   붉은 갈색입니다. 회색 그늘을 쓰는 순간 플라스틱이 됩니다.
2. **한 면을 한 색으로 칠하지 않는다.** 그라디언트 위에 큰 얼룩(radial gradient)을
   대여섯 개 얹으면 '칠한 면'이 '쌓인 가루'가 됩니다.
3. **능선에는 밝은 선과 어두운 선이 붙어 있다.** 잔물결 한 줄을 그릴 때
   위쪽에 밝은 선, 0.5px 아래에 어두운 선을 겹치면 즉시 입체가 됩니다.
4. **선은 끊어져야 한다.** 모래 잔물결을 끝에서 끝까지 이으면 그 순간
   **나뭇결**이 됩니다. 중간을 끊고 진폭을 흔드세요.
5. **알갱이는 세 톤 이상 섞는다.** 밝은 알·중간 알·어두운 알. 한 톤이면 노이즈,
   세 톤이면 가루입니다.
6. **가장자리를 또렷하게 두지 않는다.** 눈 둔덕의 테두리를 선명하게 그리면
   '흰 공 세 개'가 됩니다. 알파를 0으로 빼서 주변에 녹아들게 하세요.
7. **윤곽 대신 반사를 그린다.** 굵은 알갱이에 1px 그림자를 붙이면 표면 '위에'
   놓인 것으로 읽힙니다.

모든 무늬는 `rnd1(t.seed, k)` 처럼 **타일마다 고정된 난수**로 배치하세요.
`Math.random()` 을 쓰면 매 프레임 무늬가 요동칩니다.

## 2. 절차적 노이즈 텍스처 (파일 없이 가장 사실적)

값 노이즈(value noise)를 옥타브로 쌓아 타일 하나 크기의 오프스크린 캔버스에
한 번만 굽고, 그 뒤로는 그 캔버스를 패턴으로 찍어 쓰는 방식입니다.
재질마다 딱 한 번만 계산하므로 비용은 사실상 0입니다.

```js
/** 재질 하나당 한 번만 구워서 재사용하는 질감 캔버스 */
function bakeGrain(w, h, tint, octaves) {
  var c = document.createElement('canvas');
  c.width = w; c.height = h;
  var x = c.getContext('2d');
  var img = x.createImageData(w, h), d = img.data;
  for (var j = 0; j < h; j++) {
    for (var i = 0; i < w; i++) {
      var v = 0, amp = 1, f = 1 / 16, sum = 0;
      for (var o = 0; o < (octaves || 4); o++) {
        v += amp * valueNoise(i * f, j * f);
        sum += amp; amp *= 0.5; f *= 2;
      }
      v /= sum;
      var k = (j * w + i) * 4;
      d[k] = tint[0]; d[k + 1] = tint[1]; d[k + 2] = tint[2];
      d[k + 3] = Math.round(v * 90);        // 알파로만 얹어 기존 색을 살린다
    }
  }
  x.putImageData(img, 0, 0);
  return c;
}
```

굽은 캔버스는 `ctx.createPattern(c, 'repeat')` 로 만들어, 다이아몬드를 `clip()` 한 뒤
`Iso.pushSurface()` 와 같은 행렬 안에서 칠하면 **바닥에 깔린 것처럼** 보입니다.
`ART` 함수 안에서 이렇게 씁니다.

```js
ctx.save();
diamond(ctx, cx, cy, 0.99, 0.99); ctx.clip();
ctx.transform(hw, hh, -hw, hh, cx, cy);   // 단위 정사각형 -> 다이아몬드
ctx.fillStyle = grainPattern;              // 모듈 상단에서 한 번만 만든 것
ctx.fillRect(-0.5, -0.5, 1, 1);
ctx.restore();
```

> ⚠ 패턴은 **한 번만** 만들어 모듈 변수에 보관하세요. 프레임마다
> `createPattern` 을 부르면 30장 타일 × 60fps 에서 바로 느려집니다.

## 3. 저작권 프리(CC0) 소재를 구할 곳

아래는 전부 **CC0(퍼블릭 도메인 수준)** 를 표방하는 곳입니다.
다만 사이트가 CC0라도 **개별 파일이 예외일 수 있으니 받을 때 라이선스 표기를 꼭 확인**하세요.
교실에서 쓰거나 웹에 올릴 거라면 이 확인 한 번이 나중을 지켜 줍니다.

### 3.1 재질 텍스처 (모래·눈·나무 표면 사진) — 이 게임에 가장 잘 맞음

| 사이트 | 내용 |
|---|---|
| **ambientCG** (ambientcg.com) | CC0 PBR 텍스처. `Ground`, `Snow`, `Sand` 카테고리에 심리스 이미지가 수백 장 |
| **Poly Haven** (polyhaven.com/textures) | CC0 텍스처·HDRI. 품질이 아주 고르다 |
| **ShareTextures**, **TextureCan** | CC0 표방. 개별 확인 권장 |

**쓰는 법:** 1K(1024px) 컬러맵을 받아 **256×256 으로 줄이고** WebP/PNG로 저장한 뒤,
2절의 패턴 방식 그대로 `createPattern(img, 'repeat')` 에 넣습니다.
원본 그대로 쓰면 타일 하나가 원본의 1/6만 보여서 질감이 너무 크게 나옵니다.

타일 색은 지금 `MATERIALS[].top/topDark` 그라디언트가 정하고 있으므로,
사진은 **흑백으로 바꿔 `globalCompositeOperation = 'overlay'` 로 얹는 것**이
가장 안전합니다. 색까지 사진에서 가져오면 18종의 색 구분이 무너집니다.

### 3.2 아이소메트릭 타일 스프라이트 (그림 자체를 받아 쓰기)

| 사이트 | 내용 |
|---|---|
| **Kenney** (kenney.nl/assets) | 전부 CC0. `Isometric Blocks`, `Isometric Landscape` 등 아이소메트릭 팩 다수. 이 게임의 2:1 다이아몬드와 모양이 맞는다 |
| **OpenGameArt** (opengameart.org) | 검색 후 **License 필터를 CC0 로** 좁혀야 한다. 라이선스가 섞여 있다 |
| **itch.io** 의 `game assets` → `free` 태그 | 좋은 팩이 많지만 라이선스가 제각각. 반드시 개별 확인 |

> 스프라이트로 갈아타면 균열·눌림·부서짐 연출을 전부 다시 만들어야 합니다.
> 지금은 그 연출이 코드로 되어 있어서 상태마다 그림이 저절로 변합니다.
> **표면 질감만 텍스처로 바꾸고 구조는 지금 코드를 유지**하는 쪽을 권합니다.

### 3.3 3D로 한 번 렌더해서 스프라이트로 굽기

| 사이트 | 내용 |
|---|---|
| **Quaternius** (quaternius.com) | CC0 3D 모델 팩 |
| **Kay Lousberg** (kaylousberg.com) | CC0 3D 키트. 아기자기한 스타일 |
| **Poly Pizza** (poly.pizza) | CC0/CC-BY 혼재. 필터 확인 |

Blender에서 **직교 투영(Orthographic) + 카메라 회전 Z 45° / X 54.736°** 로 놓으면
정확한 2:1 아이소메트릭이 나옵니다. 여기에 3.1의 CC0 재질을 입혀 렌더하면
지금 타일과 같은 각도의 스프라이트를 얻을 수 있습니다.

### 3.4 소리

이 게임의 녹음은 **Pixabay**(pixabay.com/sound-effects)에서 받은 것들입니다.
파일 이름 앞이 원작자 표기입니다. **Freesound**(freesound.org)도 좋은데
CC0·CC-BY·CC-BY-NC가 섞여 있으니 필터를 꼭 거세요.
받은 뒤에는 `tools/prep-steps.py` 로 한 걸음씩 자르고 음량을 맞추면 됩니다
(`docs/AUDIO_MAPPING.md` 참고).

## 4. 무엇부터 하면 이득이 큰가

1. **1절의 7가지 규칙**을 나머지 재질에도 적용 — 코드만 고치면 되고 효과가 즉시 보입니다
2. **2절의 절차적 노이즈**를 모래·눈·나무·솜에 도입 — 파일 0개 원칙을 지키면서 질감이 크게 오릅니다
3. **3.1의 CC0 텍스처**는 그 다음 — 용량과 라이선스 관리가 따라붙습니다

3.2의 스프라이트 교체는 마지막입니다. 이 게임에서 타일 그림은 정적인 장식이 아니라
**소리를 예고하고 상태를 보여 주는 장치**라서, 그림을 밖에서 들여오는 순간
그 연결이 끊어집니다.
