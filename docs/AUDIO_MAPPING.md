# 오디오 에셋 매핑 가이드

> 구현: `js/audio.js` · 매니페스트: `assets/audio/manifest.json`

---

## 0. 요약

이 게임은 **오디오 파일 0개로도 완전히 동작**합니다. 모든 소리가 Web Audio API로
실시간 합성되기 때문입니다. `assets/audio/manifest.json`에 파일을 등록하면
해당 키의 합성음이 샘플로 **대체**되고, 등록하지 않은 키는 계속 합성음을 씁니다.
즉 **부분 교체가 가능**합니다.

현재 12종 중 **8종은 실제 녹음**을, 4종은 합성음을 씁니다.

| | 재질 |
|---|---|
| 녹음 | 키캡 · 나무 · 젤리 · 에어캡 · 슬라임 · 낙엽 · 모래 · 눈 |
| 합성 | 솜 · 구슬볼 · 유리구슬 · 스펀지 |

녹음 쪽은 재질마다 변형을 4~5개씩 두고 밟을 때마다 번갈아 재생합니다.
같은 파일이 반복되면 ASMR이 아니라 '녹음 재생'으로 들리기 때문입니다.

## 1. 합성 모형

v2부터 **모달 합성(modal synthesis)** 을 씁니다. 두드린 물체의 소리는
"고유 주파수에서 각자 다른 속도로 감쇠하는 사인 모드의 합"입니다.
단일 오실레이터로는 절대 나오지 않는 재질감이 여기서 나옵니다.

모든 타격음은 **트랜지언트 / 바디 / 테일** 3단으로 나뉩니다.

| 단계 | 역할 | 구현 |
|---|---|---|
| 트랜지언트 | 표면이 닿는 순간의 딱·톡 | 3~16ms 노이즈 버스트 (하이패스/밴드패스) |
| 바디 | 물체의 공명 = 재질의 정체 | `modalVoice()` — 비조화 모드 3~5개 |
| 테일 | 결·부스러짐·잔향 | `granular()` 미세 알갱이 + 컨볼루션 잔향 |

재질별 모드비(첫 모드를 1로 둔 비율):

| 재질 | 기본 주파수 | 모드비 | 감쇠 |
|---|---|---|---|
| 키캡 | 205Hz | 1 : 1.93 : 3.41 | **38ms** (짧아야 '딸깍') |
| 나무 | 132Hz | 1 : 2.14 : 3.87 | **82ms** |
| 솜 | 76Hz | 1 : 1.73 | 240ms (어택 14ms) |
| 유리구슬 | 880Hz | 1 : 2.45 : 4.11 : 6.83 | 950ms (가장 김) |
| 구슬볼 | 420~980Hz 무작위 | 알마다 독립 모드 5~9개 | 50~110ms |
| 정답 종 | 펜타토닉 | 1 : 2.76 : 5.40 : 8.93 | 750ms |

### ⚠ 합성에서 하지 말아야 할 것 (전부 실제로 겪은 실패)

| 하면 안 되는 것 | 어떻게 들리나 | 대신 |
|---|---|---|
| 모달에 LFO 비브라토 | 곧바로 **전자음/신스**가 된다 | `toneVoice` 의 피치 글라이드로 출렁임을 만든다 |
| 타격음의 모달 감쇠를 100ms 이상 | 음정이 들려 **북·마림바**가 된다 | 40~90ms로 강하게 감쇠 |
| 처프에 Q 12 이상 | **휘파람·새소리**가 된다 | Q 4~6의 넓은 크리크 |
| 사각거림을 이산 알갱이로만 | **지직거리는 노이즈**가 된다 | 연속 노이즈를 깔고 굵은 알갱이만 얹는다 |

**젤리·슬라임**은 모달을 쓰지 않습니다. 젤리는 300→98Hz 피치 글라이드,
슬라임은 공명 로우패스(Q 5~6)가 열렸다 닫히는 왕복으로 만듭니다.
이 왕복이 '찌걱'의 정체입니다.

**공명이 없는 재질**(낙엽·모래·눈·에어캡)은 `granular()` 가 주역입니다.
수십 개의 알갱이를 시간(앞쪽에 몰리게)·주파수·좌우로 흩뿌립니다.
모래는 연속 노이즈 두 겹 + 굵은 알갱이 9알, 눈은 크리크 9회 + 알갱이 16알을 씁니다.

**삐걱이는 재질**(눈·스펀지)은 `squeak()` 를 씁니다.
Q 4.5의 **넓은** 대역이 위로 쓸려 올라가며 여러 번 끊기는 크리크입니다.
Q를 높이면 휘파람이 되므로 절대 올리지 마세요.

**휴머나이즈** — 매 타격마다 피치 ±3%, 모드별 ±1.2%, 알갱이 게인 0.35~1.15배,
노이즈 버퍼 읽기 위치가 전부 무작위로 흔들립니다. 같은 타일을 연달아 밟아도 같은 소리가 나지 않습니다.

## 1.5 시그널 체인

```
  각 사운드 보이스
        │
        ▼
  ┌───────────────┐   x = 화면상 캐릭터 좌우 위치(-3.2 ~ +3.2)
  │  PannerNode   │   z = -1.4 - depth*3.0   (멀수록 뒤로)
  │ HRTF, inverse │   ← 바이노럴 정위
  └───────┬───────┘
          ├────────────▶ dryBus ─────────────────────┐
          │                                           ▼
          └──▶ sendGain ──▶ wetBus(0.16) ──▶ Convolver(IR 0.85초, 어둡게)
                                                      │
                          preMaster ◀─────────────────┘
                              │
                     lowShelf(180Hz +3.5dB, 근접 마이크 감각)
                              │
                     Compressor(-14dB, ratio 6) ← 겹칠 때만 부드럽게 제어
                              │
                     masterGain(0.95) ──▶ destination / Analyser
```

- **그래뉼러 확산:** `spatialTrio()` 가 좌·중·우 세 갈래 패너를 만들어
  알갱이를 흩뿌립니다. 낙엽을 밟으면 머리 주변을 감싸는 느낌이 납니다.
- **잔향이 짧고 어두운 이유:** ASMR은 "가까이서" 들려야 합니다.
  초기 반사 4개를 심은 0.85초 IR을 로우패스로 어둡게 깎았습니다.

- **바이노럴:** `PannerNode.panningModel = 'HRTF'`. 리스너는 원점에서 −Z를 바라봅니다.
  캐릭터가 화면 왼쪽에 있으면 왼쪽 귀에서, 오른쪽에 있으면 오른쪽 귀에서 들립니다.
  `SK.Game.panOf(gx, gy)`가 카메라 기준 화면 x를 −1~+1로 정규화해 넘깁니다.
- **잔향:** 지수 감쇠 노이즈로 임펄스 응답을 즉석 생성 — 작은 방 느낌. 외부 IR 파일 불필요.
- **레벨 미터:** 마스터에 `AnalyserNode`가 붙어 있고 `SK.Audio.getLevel()`이 RMS를 0~1로 돌려줍니다.
  캐릭터 주변 오라 링과 헤드폰 이어컵 발광이 **실제 출력 레벨**에 맞춰 맥동합니다 —
  소리와 화면이 코드 수준에서 묶여 있는 지점입니다.
  음량 밸런스를 잴 때도 이 값을 씁니다(6장).

## 3. 매니페스트 사용법

`assets/audio/manifest.json`:

```json
{
  "basePath": "assets/audio/",
  "samples": {
    "step_leaf": "leaf_crunch.wav",
    "step_snow": ["snow_1.wav", "snow_2.wav", "snow_3.wav"],
    "step_wood": { "files": ["wood_1.wav", "wood_2.wav"], "gain": 0.32 }
  }
}
```

값은 세 가지 형태를 씁니다.

| 형태 | 뜻 |
|---|---|
| 문자열 | 그 키를 파일 하나로 대체 |
| 배열 | **변형**. 재생할 때마다 다른 파일이 쓰이며, 같은 것이 연달아 나오지 않습니다 |
| `{ files, gain }` | 변형에 더해 그 키에만 게인 보정 |

- 값이 `http(s)://`, `/`, `assets/`로 시작하면 그대로 쓰고, 아니면 `basePath`를 앞에 붙입니다.
- **파일이 없거나 디코딩에 실패해도 조용히 무시**되고 합성음이 그대로 쓰입니다(게임은 멈추지 않습니다).
- 적용된 키는 콘솔에 `[audio] 샘플 에셋 적용: step_snow×5, …` 처럼 변형 개수와 함께 찍힙니다.
- `samples`가 비어 있으면 네트워크 요청 자체를 하지 않습니다.
- `step_<재질>_stomp` 이 없으면 강하게 내려찍을 때도 `step_<재질>` 를 더 크게 재생합니다.
  (예전에는 합성음으로 떨어져, 같은 타일인데 세게 밟으면 재질이 바뀐 것처럼 들렸습니다.)

코드에서 직접 등록할 수도 있습니다:

```js
SK.Audio.registerSampleMap({ step_jelly: ['assets/audio/jelly_1.wav', 'assets/audio/jelly_2.wav'] })
  .then(loaded => console.log('적용됨:', loaded));
```

### 게인은 왜 따로 필요한가

녹음은 파일마다 마이크 거리와 압축이 달라서, 파형 레벨을 맞춰도 게임 안에서는
체감 음량이 3배까지 벌어집니다. 그래서 `manifest.json` 의 `gain` 은
**게임에서 직접 재어 정한 값**입니다. 재는 방법은 6장에 있습니다.

## 4. 녹음 규격

| 항목 | 권장값 |
|---|---|
| 포맷 | WAV(PCM 16/24bit) 또는 OGG. 브라우저 `decodeAudioData` 지원 형식 |
| 샘플레이트 | 48kHz (44.1kHz도 무방 — 브라우저가 리샘플링) |
| 채널 | **모노**. 정위는 엔진의 HRTF 패너가 담당하므로 스테레오 소스는 정위가 흐려집니다 |
| 길이 | 딱딱한 재질 100~150ms · 푹신하거나 부서지는 재질 300~500ms · `quiz_step` ≤ 300ms · `quiz_solve` 1.0~1.5초 |
| 레벨 | 피크 −6dBFS. 발소리는 초당 3~4회 겹쳐 울리므로 여유가 필요합니다 |
| 전처리 | 앞뒤 무음 제거(중요 — 지연으로 들립니다), DC 오프셋 제거, 룸톤 최소화 |
| 잔향 | **드라이하게**. 엔진이 컨볼루션 잔향을 별도로 겁니다 |

## 5. 강도·피치 변조 규칙 (샘플에도 그대로 적용)

```js
// 착지 강도 — 도약 높이 + 연속 도약 체인
intensity = min(1, (power > 1 ? 0.95 : 0.45) + chain * 0.07)
intensity = min(1, intensity * 1.35 + 0.25)          // 큰 점프(stomp)일 때
playbackRate = (0.88 + intensity * 0.34) * (stomp ? 0.82 : 1)
gain         = 0.5 + 0.5 * intensity
```

즉 **연속으로 빠르게 뛸수록 높고 크게**, 큰 점프 착지는 더 낮고 묵직하게 울립니다.
샘플을 쓸 때도 이 배속·게인이 그대로 곱해지므로, 피치 변화가 자연스러운 소재를 고르세요.

`quiz_step` 샘플은 순번 `index`에 대해 `1.0595^(index*2)`배(= 온음씩 상승)로 재생됩니다.
그래서 **음정이 뚜렷한 소재(피아노 등)는 부적합**하고, 클릭·팝·톡 같은 무음정 소재가 좋습니다.

## 6. 음량 밸런스

재질마다 주파수 분포가 달라 **같은 게인이 같은 크기로 들리지 않습니다.**
저역이 풍부한 재질(솜·젤리·나무)은 RMS가 크게 잡히고, 고역 그래뉼러(낙엽·에어캡)는 작게 잡힙니다.
그래서 각 레시피의 기본 게인 `g` 는 수치를 맞춘 것이 아니라 **들리는 크기를 맞춰** 조정돼 있습니다.

측정한 값 (`intensity: 0.45` 한 번 타격, `getLevel()` 피크):

| 재질 | 레시피 게인 `g` | 측정 레벨 |
|---|---|---|
| 젤리 | 0.048 + 0.062×i | 0.59 |
| 스펀지 | 0.076 + 0.10×i | 0.58 |
| 모래 | 0.30 + 0.39×i | 0.55 |
| 솜 | 0.050 + 0.062×i | 0.50 |
| 낙엽 | 0.19 + 0.25×i | 0.49 |
| 구슬볼 | 0.13 + 0.17×i | 0.49 |
| 유리구슬 | 0.072 + 0.092×i | 0.46 |
| 눈 | 0.42 + 0.55×i | 0.45 |
| 나무 | 0.060 + 0.078×i | 0.45 |
| 에어캡 | 0.22 + 0.26×i | 0.44 |
| 키캡 | 0.145 + 0.190×i | 0.44 |
| 슬라임 | 0.068 + 0.090×i | 0.42 |

최대/최소 비 **1.39배** — 12종이 거의 같은 크기로 들립니다.

게인 숫자 자체는 재질끼리 비교할 수 없습니다. 모래·눈·낙엽의 `g` 가 유난히 큰 것은
그 값이 **여러 겹의 노이즈와 알갱이에 나뉘어 들어가기** 때문입니다.

**게인을 바꿨다면 반드시 다시 재세요.** 브라우저 콘솔에서:

```js
// 무작위성이 있으므로 여러 번 평균 낼 것
let sum = 0;
for (let r = 0; r < 4; r++) {
  await new Promise(s => setTimeout(s, 620));
  let peak = 0;
  SK.Audio.step('leaf', { intensity: 0.45, pan: 0 });
  for (let k = 0; k < 16; k++) { peak = Math.max(peak, SK.Audio.getLevel()); await new Promise(s => setTimeout(s, 22)); }
  sum += peak;
}
console.log(sum / 4);   // 0.35 ~ 0.62 범위면 정상
```

1.0에 붙으면 리미터를 때리고 있다는 뜻이니 게인을 내리세요.

피드백 사운드는 보상 신호이므로 발소리보다 조금 크게 둡니다 (정답 0.67, 완성/파괴는 클라이맥스).
도약 휘익은 배경음에 가깝게 아주 작습니다(약 0.04).

마스터: 게인 0.95 / 잔향 send 0.16 / 리미터 −14dB ratio 6.

## 6.5 소리 ↔ 시각 대응표

모든 사운드는 짝이 되는 시각 효과를 함께 냅니다. 사운드를 추가하면 여기도 함께 추가하세요.

| 사운드 | 시각 효과 |
|---|---|
| `step(mat)` | `Particles.stepBurst()` — 재질 색 파문 링 + 먼지, 타일 표면 발광(`t.flash`) |
| `step(..., stomp)` | 위 + 흰색 큰 링 + `쿵!` 텍스트 + 카메라 흔들림 |
| `crack(mat, stage)` | `Particles.crackBits()` + 타일 위 균열선 누적, 에어캡은 알이 하나씩 사라짐 |
| `shatter(mat)` | `Particles.shatter()` — 파편 + `CRUNCH!` / `POP-POP!` + 타일 소멸 |
| `whoosh(power)` | `Particles.trail()` — 도약 궤적 |
| `stepCorrect(i)` | 별빛 + 초록 링 + `TOK!` 계열 텍스트 + 슬롯 채움 |
| `solveBurst()` | `Particles.celebrate()` — 삼중 링 + `CRACKLE-POP!` + `PERFECT!` |
| `wrong()` | 붉은 링 + `THUD…` + 화면 흔들림 + 캐릭터 멈칫 |
| (재질별) | `Particles.IMPACT[fx]` — press/puff/jiggle/goo/chunk/pop/balls/grain/sparkleRing/flake |
| (모든 착지) | 타일에 밟은 자국(`t.mark`)이 남아 서서히 사라짐 |
| 파괴 / 완성 | 화면 전체 플래시 + `Particles.tileBreak()` 네 조각 + 어두운 구멍 |
| (모든 소리) | 캐릭터 오라 링 — `Audio.getLevel()` 실시간 RMS로 맥동 |

## 7. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 아무 소리도 안 남 | 브라우저 자동재생 정책. **"산책 시작하기" 버튼을 눌러야** `AudioContext`가 열립니다 |
| 좌우 구분이 안 됨 | 이어폰/헤드폰을 쓰세요. 스피커에서는 HRTF 효과가 크게 줄어듭니다 |
| 샘플이 적용 안 됨 | 콘솔의 `[audio]` 로그 확인 → 404거나 디코딩 실패. `file://`에서는 `fetch`가 막히므로 로컬 서버로 여세요 |
| 소리가 지직거림 | 샘플 피크가 0dBFS에 붙어 있는 경우. −6dBFS로 정규화 |
| 발소리가 늦게 들림 | 샘플 앞부분의 무음 구간을 제거하세요 |
